Academic Project

Chronic Kidney Disease Predictor

Clinical Machine Learning · Healthcare Data · Streamlit

An interactive machine learning application for predicting chronic kidney disease from selected clinical patient measurements. The project covers data preprocessing, class balancing, model comparison, model evaluation, and deployment through a Streamlit web application.

  • Processed clinical and categorical patient data, including missing-value handling and feature encoding.
  • Applied feature scaling and SMOTE-based class balancing.
  • Compared multiple machine learning classification models.
  • Selected a Gradient Boosting classifier for the deployed application.
  • Built a Streamlit interface for entering patient measurements and obtaining a model prediction.
